# dsh-mind-sea · 小鲸鱼四层记忆框架

给 DSH（DeepSeek Harness）用的**长期记忆插件**。它把《小鲸鱼四层记忆框架》里最容易被"上下文压缩/新开会话"冲掉的两层落成文件：

```
L0 人设  角色卡（人格 + 操作两份合并）      → 沿用宿主自己的角色卡机制
L1 识海  事实节点图 + 权重衰减 + 图扩散召回  → mind_graph.json
L2 日记  她自己写的当天细节与心情            → diary/riji.jsonl
L3 会话  DSH 的对话历史（可以丢）            → DSH 自己管
```

铁律：**只有 L3 可以丢**。L0/L1/L2 都是本地文件，会话压缩或清空，她照样记得重要的事。

## 它和"每轮全量注入"的插件差在哪

- 常驻注入只有 **core 全量 + 少量 important**（默认 12 条，约 900 字节），每轮恒定，不会滚雪球。
- 更细的事靠 **`mind_recall` 按话题现查**。
- 没有相关记忆时**宁可返回空**，不硬凑——避免她以为"记得"然后编。

## 安装

```
dsh plugin --profile <你的profile> add /path/to/dsh-mind-sea
```

或者在 DSH 里用插件管理器的「从目录安装」选这个目录。

装好后重启，插件面板会出现「小鲸鱼识海」。

## 提供的工具

| 工具 | 作用 |
|---|---|
| `mind_remember` | 记一条事实（≤200 字，一条一件事）。她自己只能写 normal/important，`core` 只能由主人加 |
| `mind_recall` | 按话题检索旧事（字面匹配 + 图扩散 + 权重加权，低于阈值不返回） |
| `mind_diary_write` | 写日记（≤300 字，一天 1~3 条） |
| `mind_diary_read` | 读最近日记 |
| `mind_stats` | 看规模：节点数 / 层分布 / 最老最新 / 权重最高的几条 |
| `mind_consolidate` | 手动跑一次夜间巩固 |

## 权重与衰减

```
有效权重 = 基础权重 × (source == owner ? 1.8 : 1.0) × exp(-天数 / 半衰期)

基础权重   core 10 / important 3 / normal 1
半衰期     core 3650 天 / important 30 天 / normal 7 天
淘汰线     非 core 且有效权重 < 0.06
容量       5000 节点，超了按有效权重淘汰
```

## 召回算法

```
查询分词（中文 2 字滑窗 + 英文词，过滤虚词与通用口语词，单字不参与）
  → 字面分：命中数 / min(查询词数, 4)（长词覆盖短词，避免「东西」重复计「东」「西」）
  → 图扩散：命中节点沿边扩 2 跳，每跳 ×0.6
  → 最终分 = 相关性 × (0.5 + min(有效权重, 12) / 24)
  → 低于阈值丢弃（默认 0.25），取 top N
  → 被召回的节点强化：hits + 1、weight + 0.08
```

## 夜间巩固

三个触发点共用一个入口，不会重复跑：

```
每天 23:50 定时器（可改时间/关闭）
App 启动 8 秒后检查"今天是否已经巩固过"，没跑过就补跑
设置页「立即跑一次」
```

> ⚠️ 定时器只在 DSH 运行时工作。没有 cron 系统也能用，但宿主退出时不会跑——启动补跑会补上。


## 多域：人设与记忆按会话分离

不只是一个识海。可以建**多个识海域**和**多份人设**，再把会话绑到任意一组上：

```
$DSH_HOME/mind/
  bindings.json            { "<sessionId>": { profile, sea } }
  profiles/global.md       全局默认人设
  profiles/<id>.md         其他人设（工作态、某个角色的另一版……）
  seas/global/             全局识海
  seas/<id>/               其他识海（各自独立的 mind_graph + diary）
```

- **未绑定的会话** 一律用 `global` 人设 + `global` 识海。
- **多个会话可以绑同一个域**，共用同一套记忆和人设（比如 QQ 私聊和桌宠是同一个她）。
- 绑定后，该会话的注入由 `agent/created` 事件挂上专属 section（scoped 覆盖全局），`mind_*` 工具也自动读写该域。

### 启动校对（失效绑定检测）

每次启动 9 秒后自动检查一次：读 `workspace.json` 里**未归档**的会话，逐个对绑定。
指向已删除/已归档会话的绑定会被标成「会话不存在」，在设置页「绑定」页顶部红条里显示，可一键清理（只删绑定，不动任何记忆）。

设置页里也能手动点「重新检查」。

## 设置页（分页）

| 页签 | 内容 |
|---|---|
| 概览 | 当前域统计、上次巩固时间、域/人设/绑定计数 |
| 识海 | 域列表（新建/删除/切换）、该域记忆列表（升 core / 删）、手动记一条、日记 |
| 人设 | 人设列表（新建/删除/编辑）、正文编辑框 |
| 绑定 | 会话列表（失效的标红）、多选批量绑到某个人设+识海、解除、清理失效 |
| 参数 | 注入条数、召回条数/阈值、每天自记上限、注入人设开关、自动巩固与时间、按标签抽象 |

## 设置页（1.0 版结构说明）

插件面板 → 小鲸鱼识海，四块：

- **识海概览**：节点数 / 层分布 / 关联边 / 日记天数 / 上次巩固时间
- **参数**：常驻注入条数、召回条数、召回阈值、每天自记上限
- **夜间巩固**：开关、执行时间、是否按标签抽象、立即跑一次
- **人设卡（L0）**：人格.md / 操作.md 两个文本框 → 保存并合并 → 应用到灵魂卡（自动备份）

人设卡默认指向 `$DSH_HOME/roles/`，需要先有三份文件：

```
roles/小鲸鱼.人格.md   ← 她自己那半（你是谁/称呼/说话方式/关系）
roles/小鲸鱼.操作.md   ← 主人维护那半（记忆用法/时间感/聊天节奏/边界）
roles/小鲸鱼.md        ← 合并产物（脚本生成，≤6000 字）
roles/build-card.mjs   ← 合并脚本
```

## 数据文件

```
$DSH_HOME/mind/
  mind_graph.json      L1 节点与边
  config.json          设置页写入的参数
  state.json           上次巩固日期（用于启动补跑）
  diary/riji.jsonl     L2 日记
```
